# Evidence plan

Apply the [common evidence contract](evidence.md) before this procedure.

`evidence plan` takes `plan` with version 1 and these required fields: `decision_ref`; `criteria` (`id`, `checks` command IDs, `behavior` boolean); `checks` (`id`, exact `argv`, relative `cwd`, `timeout` 1–300 seconds, explicit credential-free `env` containing `PATH` and optionally `LANG`, `LC_ALL`, `TZ`; `effects` with `kind` read-only/disposable, `inspection_ref`, and `network`, `production`, `publish`, `migrations` all false; `baseline` status passed/failed/not-run and reference; relative `dependencies`); `reviews` for `general` and `security` with `applicability` required/inapplicable/unresolved, reason, and independent boolean; `security_impact` status assessed/unresolved, reason, reference; `base`, `comparison` endpoint/merge-base, `nontrivial`, absolute safe `instructions`, relative `exclusions` with impact, and `review_limit` 1–8. There must be 1–32 criteria; checks may be empty only when behavior is observed, otherwise include up to 32 accepted commands. Optional `relevant_untracked` lists relevant ignored paths; optional check `thresholds` can only be `{"exit_codes":[0]}`. Mutable/disposable checks require declared `resources` using `_claims` in [runtime/delegation.py](../runtime/delegation.py). Genuinely read-only checks may derive read claims from declared dependencies; an empty or unknown footprint serializes affected checkout work. Never infer mutable-resource isolation. A comparable failed baseline may include its integer `exit_code` and SHA-256 `output_digest`; only an exact signature match is pre-existing, otherwise failure comparison remains unresolved. Changing accepted rules requires `change_decision_ref`.
