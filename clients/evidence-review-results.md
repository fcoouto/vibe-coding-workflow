# Collect and assess a native review

Apply the [common evidence contract](evidence.md) before this procedure.
Use the [current native review bindings](evidence-review-bindings.md) when relying on native results.

Use `delegation observe` for the same prepared reviewer and actual parent-turn/start-item identity before quality collection. It can record incomplete or mutated work without accepting review quality. `evidence review collect` requires that attempt plus native `parent_turn_id` and `spawn_item_id`; it fetches the completed/current-candidate receipt and report, then correlates the same child, start, turn, result item and raw-result digest with lifecycle observation. A mismatch, invalid report or changed candidate cannot pass. First collection requires the D5 attempt to remain `reserved`; no same-attempt recollection API exists. Collection and assessment neither launch another reviewer nor release ownership. A valid report may be assessed while stopped-descendant proof remains unresolved; complete exact reconciliation through [native recovery](delegation.md#observe-and-reconcile-independently). `assess` requires the same `attempt_id` and an `assessment` with covered `coverage` and `criteria`, coordinator `qualification`, `independence`, `semantic_coverage`, finding `dispositions` (`finding_id`, `status` resolved/accepted/open, reference), and `decision_refs`. Optional `rechecked_findings` binds a fresh review attempt and finding ID to resolved/open status and reference. High/critical confirmed security findings cannot be accepted.
