# Onboard my Project

Use for an explicitly selected existing project, update, repair or recovery. For basic onboarding, inspect relevant instructions/configuration, assess the complete Toolkit catalog for relevance, make authorized changes recoverably, and leave useful guidance, working project commands, relevant checks, limitations and an undo location.

Read [the procedure](references/procedure.md) for onboarding and [apply and recovery](references/apply-and-recovery.md) for authorized file changes or undo. Read [managed planning](references/managed-plan.md) only when using the managed dispatcher; when presenting its proposal, read [Reviewed Configuration](references/reviewed-configuration.md). Read [qualification](references/qualification.md) only for selected managed activation or adapter validation. Load runtime, delivery and external-route procedures only when selected. Preserve permissions, actual writer ownership, user edits and recovery provenance. Ordinary development needs no runtime activation or qualification campaign.
