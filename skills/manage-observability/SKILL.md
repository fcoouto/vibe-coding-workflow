# Manage Observability Integration

Read the [local procedure](references/procedure.md), then only the selected provider's reference when needed. Keep provider selection separate from Project enrollment and machine preparation.

Observability is optional and disabled by default. Preserve user authorization, destination boundaries, native model settings and required local execution evidence. Export permission never follows from a connection, a supplied report or this skill's availability.

The current package supports preparation guidance and existing local task preparation, not persistent observability settings or live collection. Report pending capabilities honestly; never invent an enable command, configuration store or successful activation.
