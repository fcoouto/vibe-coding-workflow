# Manage OpenRouter Integration

Read the [local procedure](references/procedure.md) for the requested control. Keep
activation separate from Onboard my Project; its optional follow-up is an offer.

Default to native execution. Save authorized enablement only for the supported
enrolled checkout. Report saved consent, local configuration and observed execution
separately. Preserve native model choices, authentication and customizations.

OpenRouter owns spending limits. Never store keys in workflow settings, treat an
account connection as consent, or infer Project-wide membership. Disable blocks
new managed admissions; already-admitted work can settle and receive native
verification. It does not revoke account access or stop direct MCP calls.
