# Workstreams

Choose only the requested route:

- **Naming only:** read [naming and status rules](../../clients/workstreams-naming.md).
  Load only that section; no enablement or dispatch.
- **Management:** read the [controls](references/procedure.md#workstreams-controls)
  for enable, disable or status. Do not load execution details.
- **Execution:** observe saved mode through those controls, then load the
  [execution contract](../../clients/workstreams.md) for a suitable enabled
  assignment. If disabled, use [normal delegation](../../clients/delegation.md);
  never enable implicitly.

For combined requests, apply controls first. New Codex runtime scopes start enabled; existing preferences remain.
Enabling alone starts no workers or integrations and qualifies no client capability.
Preserve native settings, ownership, budgets and required review. After disable,
collect and reconcile existing output without new managed dispatches or continuations.
