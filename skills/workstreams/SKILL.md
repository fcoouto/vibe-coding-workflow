# Workstreams

For naming only, read the [naming and status rules](../../clients/workstreams.md).
Use supported display-title controls without starting or changing task work.

For automatic adoption, accepted progress, manual edits or missed updates, read
[title synchronization](../../clients/workstreams-titles.md). Bind an existing
workflow task; use its exact state and accepted milestones. Keep parent/child
identity stable across renames and fixes.

Preserve native settings, lineage, ownership, permissions and completion evidence.
A title grants no authority. Adopt topic-only edits; preserve other manual edits
and pause synchronization until explicit resumption. No watcher or extra model
turn. Use the existing task, evidence and delegation contracts for those actions.
