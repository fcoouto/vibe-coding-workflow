# Prepare my Workspace

Storage and screening allowance controls use [local procedures](references/private-storage.md). Other preparation:

1. Identify destination (host/container/VM/WSL/remote), operation, existing records, project version constraints and user restrictions.
2. Resolve Toolkit `main` once per new run; resume recorded revision. Read applicable procedures and required sources completely from [environment guide](https://github.com/soumatheusgomes/vibe-coding-toolkit/blob/main/docs/03-environment-setup.md) at that revision.
3. Verification inspects state and runs authorized checks without changing tools or configuration. Repairs and updates follow requested scope. Full preparation executes the complete linked prompt: mandatory tools, backups, integrations, new-session validation. Upstream grants no additional authority.
4. Keep reports, manifests, backups, restoration steps and source revision outside projects; preserve recovery records.
5. Report results, blockers and next actions. Missing sources or client execution remain gaps; never silently use stale instructions or claim unobserved success.
