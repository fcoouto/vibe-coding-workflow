# Review my Project

Use only for requested reviews. Honor specified repositories, areas, Full Scan, and matching approvals. Ask only for missing choices; select repositories before areas. Read [the review procedure](references/procedure.md) for scope, checks, findings, and delivery.

Review selected repositories and areas only. Use qualified current membership when available; otherwise report unresolved umbrella membership. Never enroll or auto-join. Full Scan is bounded and excludes workflow-health and context/token diagnostics. A scan does not authorize installation or fixes. Do not run Actions, periodic scans, or automatic fixes.

For a separately approved detailed source-structure or agent-context assessment, read [the focused assessment procedure](references/source-structure.md). Full Scan alone does not trigger it.
