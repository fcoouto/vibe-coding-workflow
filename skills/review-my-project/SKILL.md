# Review my Project

Use only for a requested review. Honor specified repositories, areas, Full Scan, and matching approvals. Ask only for missing scope choices; never reconfirm provided choices or approvals. When selection is needed, choose repositories before areas. Read [the review procedure](references/procedure.md) for scope, safe checks, findings, and delivery.

Review only the selected repositories and areas. Use current qualified membership when available; otherwise stay within explicitly selected repositories and report unresolved umbrella membership. Never enroll or auto-join a repository. Full Scan is bounded and excludes workflow-health and context/token-efficiency diagnostics. A scan does not authorize installation or fixes; reuse matching prior separate authorization without asking again. Do not run Actions, periodic scans, or automatic fixes.
